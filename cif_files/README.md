Contains all initial cif files used for the study. 
"nsub" means n Ti have been substituted with Al. 
$x$ in Li$_{1+x}$Al$_x$Ti$_{2-x}$(PO$_4$)$_3$ can be calculated via $x = n/24$.
All cif files contain only 24 lithium atoms, as in the original LTP structures. For MD simulations, n additional Li atoms have been inserted accordingly.
